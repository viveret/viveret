I had a desktop I could theoretically run things on as a server, but I wanted to build a smaller, GPU-less machine with server architecture / specifications so that it could be more efficient and I could turn on my more power hungry desktop off at night or when I'm not using it. I could also use my server as a backup machine for my desktop.

## Steps to Building a Computer
This isn't a complete guide, but just a simple overview of what I did to build my server.
1. Choose a case size. 
2. Choose a memory and disk size, including number of drives / sticks.
3. Choose additional PCI hardware as desired.
4. Choose a motherboard that can supply everything needed for the ram and disks.
5. Choose a power supply.
6. Choose a case that can fit all the components.
7. Assemble computer.
8. Install linux.
